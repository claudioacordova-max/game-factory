# Plantilla de prototipo 3D

Base técnica reutilizable para prototipos web con Vite, React, TypeScript, Three.js y React Three Fiber. Incluye una escena estática de prueba; no incluye mecánicas ni sistemas de juego.

## Requisitos

- Node.js 20.19+ o 22.12+
- npm

## Uso

Desde esta carpeta, instala las dependencias y arranca el servidor de desarrollo:

```sh
npm install
npm run dev
```

Abre en el navegador la dirección local que muestra Vite (normalmente `http://localhost:5173`).

Para compilar y previsualizar la versión de producción:

```sh
npm run build
npm run preview
```

Al iniciar un juego nuevo, copia el contenido de esta carpeta y modifica la escena según su especificación aprobada.
